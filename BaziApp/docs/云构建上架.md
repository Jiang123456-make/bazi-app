# 灵犀八字 · 云构建上架指南（无 Mac 版）

> 你只有 Windows，但有付费开发者账号（$99/年）。本指南用 **GitHub Actions 云端 macOS** 帮你编译、签名、上传 App Store，全程不需要本地 Mac。
>
> **分工原则**：凡是「网页点按钮」和「复制粘贴文本」的，你自己做；凡是「跑命令生成文件」的，我来做（我已经生成好了 CSR 和流水线）。

---

## 一、总览：整条链路只有 3 个硬门槛

| 门槛 | 状态 | 说明 |
|---|---|---|
| ① Apple 付费开发者账号 | ✅ 你已有 | 价值 $99/年的那个，不是免费 Apple ID |
| ② macOS 编译环境 | ✅ 用云端 | GitHub 免费提供的 macOS 虚拟机，白嫖 |
| ③ 签名证书 + 描述文件 | ⏳ 待生成 | 在网页后台点几下 + 我帮你合成文件，**无需 Mac** |

流水线我已经写好（`.github/workflows/build-and-upload.yml` + `fastlane/`），CSR 私钥我也生成了（`BaziApp/certs/bazi_distribution.key` + `.csr`）。你只需要按下面 6 步操作。

## 二、6 步操作清单（照做即可）

### 第 0 步：把代码推到 GitHub 私有仓库

1. 打开 github.com → 登录 → 右上角 **+** → **New repository**
2. 仓库名填 `bazi-app`，选 **Private**（私密，别选 Public，涉及签名）
3. 创建后，GitHub 会显示一段命令。回到我这里，告诉我仓库地址（形如 `https://github.com/你的用户名/bazi-app.git`），**我来帮你推送代码**。

---

### 第 1 步：上传 CSR 换分发证书（10 分钟）

1. 打开 [developer.apple.com/account](https://developer.apple.com/account) → 登录你的付费账号
2. 点左侧 **Certificates, Identifiers & Profiles**
3. 点 **Certificates** 一栏 → 右上角蓝色 **＋**
4. 选 **Apple Distribution（App Store and Ad Hoc）** → Continue
5. 点 **Choose File**，选这个文件（我已经生成好了）：
   ```
   D:\八字APP\BaziApp\certs\bazi_distribution.csr
   ```
6. 点 **Continue** → 会下载一个 `distribution.cer` 文件
7. **把这个 .cer 文件放到 `D:\八字APP\BaziApp\certs\` 目录，然后告诉我「cer 已放好」**，我来帮你合成 .p12。

> 私钥（.key）和 CSR（.csr）我已经生成并留在本地，**绝不外传、不进 git**。

---

### 第 2 步：注册 App ID（1 分钟）

1. 仍在 **Certificates, Identifiers & Profiles** 页面 → 点左侧 **Identifiers**
2. 右上角 **＋** → 选 **App IDs** → Continue
3. **App** → Continue
4. **Description** 填 `灵犀八字`，**Bundle ID** 选 *Explicit* 填：
   ```
   com.lingxi.bazi
   ```
5. Continue → Register

> 这个 Bundle ID 必须和代码里 `project.yml` 的 `PRODUCT_BUNDLE_IDENTIFIER` 完全一致（已经是 `com.lingxi.bazi`），改不得。

---

### 第 3 步：创建分发描述文件（2 分钟）

1. 点左侧 **Profiles** → 右上角 **＋**
2. 选 **App Store Connect** 下的 **App Store** → Continue
3. 选刚才的 App ID（`com.lingxi.bazi`）→ Continue
4. 勾选第 1 步生成的证书 → Continue
5. **Provisioning Profile Name** 填一个名字，比如 `LingxiAppStore`（**记住这个名字，后面要填**）→ Generate
6. 下载 `.mobileprovision` 文件 → 放到 `D:\八字APP\BaziApp\certs\` 目录

---

### 第 4 步：创建 App Store Connect API Key（2 分钟）

1. 打开 [appstoreconnect.apple.com](https://appstoreconnect.apple.com) → 登录同一账号
2. 顶部右侧点头像 → **Users and Access**
3. 点 **Integrations** 标签页（或 **Keys** 标签页）
4. 找到 **App Store Connect API** 区域 → 点 **＋**（或 **Generate API Key**）
5. **Name** 填 `GitHubActions`，**Access** 选 **App Manager** → Generate
6. 下载 `.p8` 文件（**只能下载这一次，别丢**），同时记下：
   - **Key ID**（形如 `ABC123DEF4`）
   - **Issuer ID**（形如 `xxxx-xxxx-...`，在这个页面顶部也能看到）
7. 把 `.p8` 文件放到 `D:\八字APP\BaziApp\certs\` 目录

> 还需要你的 **Team ID**：回 [developer.apple.com/account](https://developer.apple.com/account) → 左侧 **Membership**（或顶部 **Membership details**）→ 找到 **Team ID**（形如 `9X8XXXXXXX`），记下来。

---

### 第 5 步：在 GitHub 填 8 个 Secrets（3 分钟）

现在 `D:\八字APP\BaziApp\certs\` 目录里应该已经有 3 个文件：

```
distribution.cer        (第1步下载的)
LingxiAppStore.mobileprovision  (第3步下载的，文件名可能不同)
AuthKey_XXXX.p8         (第4步下载的)
```

**告诉我「certs 目录放好了」**，我会帮你：
1. 把 .cer 和 .key 合成成 `distribution.p12`（并设一个密码）
2. 把 .p12、.mobileprovision、.p8 三个文件转成 base64 文本
3. 给你一段可以直接复制粘贴到 GitHub 的完整配置

> 也可以自己一键生成：在仓库根目录运行 `bash scripts/make-secrets.sh`，会自动合成 .p12 并在 `certs/secrets.txt` 里生成整份填写表。

然后你到 GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**，把 8 个值逐一填进去：

| Secret 名 | 填什么 |
|---|---|
| `TEAM_ID` | 你的 Team ID |
| `P12_BASE64` | .p12 的 base64 文本 |
| `P12_PASSWORD` | .p12 的密码 |
| `MOBILEPROVISION_BASE64` | .mobileprovision 的 base64 文本 |
| `PROFILE_NAME` | 描述文件名字，如 `LingxiAppStore` |
| `APPSTORE_API_KEY_BASE64` | .p8 的 base64 文本 |
| `APPSTORE_KEY_ID` | Key ID |
| `APPSTORE_ISSUER_ID` | Issuer ID |

---

### 第 6 步：在 App Store Connect 建 App + 触发流水线

1. appstoreconnect.apple.com → **My Apps** → 左上角 **＋** → **New App**
2. Platform 选 **iOS**，Name 填 `灵犀`，Primary Language 选 `Simplified Chinese`
3. **Bundle ID** 下拉选 `com.lingxi.bazi`，SKU 随便填 `lingxi001` → Create
4. 回 GitHub 仓库 → **Actions** 标签 → 左侧 **Build & Upload to TestFlight** → 右侧 **Run workflow** → 填版本号 `1.0.0`、构建号 `1` → **Run workflow**
5. 等 10~20 分钟（第一次会慢，因为要装依赖）→ 变绿 ✅ 就说明上传成功
6. 回 appstoreconnect → **TestFlight** 标签 → 会看到 build 正在处理 → 处理后即可邀请测试

---

## 三、之后正式上架 App Store（测试通过后）

1. TestFlight 测试无问题后，在 appstoreconnect 里把 App 信息补全（截图、描述、图标、隐私政策 URL、年龄分级）
2. 提交 **App Review** 审核
3. 审核通过 → 点 **Release** 正式上架

> 文案材料我已经准备好，在 `BaziApp/docs/` 里：`AppStore描述.md`（可直接粘贴）、`隐私政策.md`、`免责声明.md`。

## 四、常见问题

- **Q：第一次流水线失败怎么办？** 把 Actions 里红色的日志截图/文字发给我，我帮你排查（90% 是 secrets 填错或证书/描述文件不匹配）。
- **Q：证书过期？** Apple 分发证书有效期 1 年，到期前重新走一遍第 1、3 步，更新 secrets 即可。
- **Q：想要多台设备测试？** 走 TestFlight 邀请即可，无需注册 UDID。
- **Q：能不能直接自动上架，跳过 TestFlight？** 可以，测试稳定后我把上传目标从 TestFlight 改成直接提交 App Review，但建议先走 TestFlight 稳一版。
