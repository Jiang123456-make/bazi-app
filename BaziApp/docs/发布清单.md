# 上架发布总览

> **当前最省事路径（推荐）**：Codemagic 自动签名 → 自动上传 TestFlight → 审核上架。
> 证书/描述文件由 Codemagic 自动生成，**无需手动碰苹果后台的证书操作**。
> 分步操作见 **`docs/最省事上架-Codemagic.md`**（精确到按钮，全程只需 5 步）。

## Codemagic · 你的操作清单（5 步）

1. GitHub 建私有仓库 → 把地址发我，我推代码
2. 注册 Codemagic（免费）→ 连仓库
3. App Store Connect 生成 API Key（.p8）—— 唯一一次苹果后台操作
4. 把 API Key 填进 Codemagic
5. 点构建 → 自动生成证书 + 编译 + 上传 TestFlight

## 审核材料（已备好，在 `docs/` 目录）

- **App 名称**：灵犀 - 八字命理顾问
- **描述**：`AppStore描述.md` 内容
- **类别**：生活 / 工具
- **年龄分级**：12+
- **隐私政策 URL**：`隐私政策.md` 内容（需托管成网页）
- **免责声明**：`免责声明.md`
- **截图**：需 6.7 寸 / 6.5 寸 / 5.5 寸等尺寸，可从设计稿导出或真机/TestFlight 截图

## ⚠️ 命理类审核注意（重要）

- 全程措辞用「传统文化 / 娱乐参考」，**不要**出现「预测未来」「算命准确」「改运」等词
- App 内和 App Store 描述都保留免责声明（已内置）
- 若被拒（多为 4.3 重复 / 5.6 合规），根据拒绝原因调整文案后重新提交
