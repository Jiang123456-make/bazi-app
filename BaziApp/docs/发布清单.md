# 上架发布总览

> **当前推荐路径（无 Mac）**：GitHub Actions 云构建 → 自动上传 TestFlight → 审核上架。
> 完整分步操作见 **`docs/云构建上架.md`**（精确到点哪个按钮）。
> 本文是总览 + 备选方案 + 审核注意。

## 两条发布路径

| | 云构建（推荐） | 本地 Mac 构建（备选） |
|---|---|---|
| 需要什么 | 只有 Windows 即可 | 一台 Mac + Xcode |
| 编译在哪 | GitHub 云端 macOS | 本地 |
| 我帮你做了什么 | 流水线 + Fastlane + CSR 私钥已生成 | 代码/图标/隐私清单已就绪 |
| 你要做的 | 网页点按钮 + 填 8 个 secrets | 照 `docs/build-ios.md` 操作 |
| 详细步骤 | `docs/云构建上架.md` | `docs/build-ios.md` + `docs/submit-ios.md` |

## 云构建 · 8 个 Secrets 一览

| Secret 名 | 来源 |
|---|---|
| `TEAM_ID` | developer.apple.com → Membership |
| `P12_BASE64` | 分发证书 .p12（base64） |
| `P12_PASSWORD` | .p12 密码 |
| `MOBILEPROVISION_BASE64` | 描述文件 .mobileprovision（base64） |
| `PROFILE_NAME` | 描述文件名字 |
| `APPSTORE_API_KEY_BASE64` | App Store Connect API Key .p8（base64） |
| `APPSTORE_KEY_ID` | Key ID |
| `APPSTORE_ISSUER_ID` | Issuer ID |

## 审核材料（已备好，在 `docs/` 目录）

- **App 名称**：灵犀 - 八字命理顾问
- **描述**：`AppStore描述.md` 内容
- **类别**：生活 / 工具
- **年龄分级**：12+
- **隐私政策 URL**：`隐私政策.md` 内容（需托管成网页）
- **免责声明**：`免责声明.md`
- **截图**：需 6.7 寸 / 6.5 寸 / 5.5 寸等尺寸，可从设计稿导出或真机/TestFlight 截图

## ⚠️ 命理类审核注意（重要）

- 全程措辞用「传统文化 / 娱乐参考」，**不要**出现「预测未来」「算命准确」「改运」等词
- App 内和 App Store 描述都保留免责声明（已内置）
- 若被拒（多为 4.3 重复 / 5.6 合规），根据拒绝原因调整文案后重新提交

## 审核通过后

- App 上线 App Store，可自选发布范围（国区 / 海外）
- 建议后续更新：接大模型对话、VSOP87 分钟级节气、农历转换（代码已预留扩展点）
